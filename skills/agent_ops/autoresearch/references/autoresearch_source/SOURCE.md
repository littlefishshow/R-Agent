# Reference source

This folder stores a local reference snapshot of `karpathy/autoresearch` used to design the `autoresearch` skill.

- Upstream: https://github.com/karpathy/autoresearch
- Files captured from local workspace snapshot originally obtained via GitHub raw/API when direct clone timed out.
- Included files: README.md, program.md, prepare.py, train.py, pyproject.toml, .python-version, .gitignore.
- Note: README states MIT, but no root LICENSE file was present in the inspected snapshot; verify upstream licensing before redistributing copied code beyond local reference/use.

The reference code is not the skill runtime. It is guidance for constructing project-specific autoresearch frameworks.
