# External Repo Feature Research

## When to Use
- 用户要求调研某个本地/外部仓库中特定功能的实现方式。
- 需要在不假设文件内容的前提下，定位源码、文档、测试并总结架构。

## Procedure
1. 若目标路径在工作区外，先用只读搜索工具尝试访问；如返回 permission_required，向用户说明路径与只读操作风险并等待明确授权。
2. 先并行搜索功能关键词与候选文件名，例如：核心术语、类名、配置项、文档关键词、测试文件关键词。
3. 优先读取：
   - 核心实现文件；
   - 抽象接口/插件接口；
   - 调用入口/生命周期文件；
   - 官方 developer docs；
   - 关键测试或回归测试（用于发现边界条件）。
4. 总结时按以下结构输出：
   - 结论概览；
   - 触发机制与配置；
   - 核心算法步骤；
   - 失败/并发/安全处理；
   - 可借鉴点；
   - 关键源码位置。
5. 引用本地文件路径与行号范围，避免声称未读取过的实现细节。

## Notes
- 对工作区外仓库保持只读，除非用户明确要求修改。
- 若文档与源码不一致，以源码为准，并标注差异。
