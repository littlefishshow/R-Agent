# Autoresearch Program: coin_change_dp

## Goal
Improve a solver for the minimum coin change problem.

## Fixed evaluation
Do not modify `eval.py`, `eval.sh`, or generated `data/test_cases.json` while running optimization experiments.

## Task
Given coin denominations and an amount, output the minimum number of coins needed to form the amount, or `-1` if impossible.

## Baseline
`train/train.py` writes `submission/solver.py` containing a recursive memoized implementation and then writes predictions. It is correct on the fixed set but slower than an iterative DP.

## Optimization target
Maximize `primary_metric=score`. Correctness is mandatory; speed provides secondary improvement.

## Commands
```bash
python prepare.py
bash train/train.sh
bash eval.sh
cat metrics.json
```

## Allowed modifications
- `train/train.py`
- files under `submission/` generated by training
- documentation/reports

## Stop condition
Stop after 5 quick experiments or once accuracy is 1.0 and runtime is clearly improved over baseline.

## Completion Criteria
This project is solved only when the official evaluation in `metrics.json` reports:

- `metric_name`: `score`
- `higher_is_better`: `true`
- `score >= 0.99`

Rationale: All fixed cases correct and runtime fast enough that the score is effectively maximal.
